Quote length: 10–150 words. Use the upper range for complete resolutions; shorter quotes are fine for names, dates, and brief declarations. Include 1–3 quotes per entity. EXTRACTION RULES:

Proposed resolutions / officer recommendations:
- An agenda item with an officer recommendation becomes a `motions` entry even though no vote has occurred yet
- `motion_text`: the proposed resolution text exactly as written (may be labelled "PROPOSED RESOLUTION", "OFFICER RECOMMENDATION", "RECOMMENDATION", etc.)
- `officer_recommendation`: copy the full recommendation text verbatim — same text as motion_text if they match, or the separate officer recommendation section if different
- `outcome`: always null (the meeting has not happened yet)
- `moved_by`, `seconded_by`, `individual_votes`, `votes_for`, `votes_against`, `votes_abstain`: always null/empty (not applicable to agendas)
- Only create a motions entry when there is a proposed resolution or officer recommendation text — do not create entries for reports or information items with no associated recommendation
- `source_quotes` must never be empty. Quote the officer recommendation text verbatim.

Planning applications:
- If an agenda item relates to a development/planning application (DV, DA, planning scheme amendment, etc.), populate the `planning_application` object
- `status`: always "pending" for agenda items (the application has not been decided yet)
- Extract community submissions (objections/supports) count and any named submitters listed in the officer's report

Councillors:
- `councillors_present` and `councillors_apology`: leave as empty lists — agendas do not list attendance
- `interest_declarations`: leave as empty list — declarations occur at the meeting, not in the agenda

Public questions:
- Agendas may list submitted written questions with officer responses — extract these into `public_questions`
- If the agenda only shows a time slot for Public Question Time with no actual questions listed, leave `public_questions` as an empty list

Deputations:
- If the agenda lists scheduled deputations or presentations, extract these
- If the agenda only shows a time slot for deputations with no names, leave as empty list

Confidential items:
- If an item is marked confidential, set `is_confidential: true` and record whatever information IS available (item number, topic label)

General:
- Use ISO 8601 date format (YYYY-MM-DD) for all dates
- Infer tags on motions from context: e.g. "planning", "budget", "infrastructure", "community", "governance", "procedural", "appointment", "tender", "personnel"
- If a value is not present in the text, use null or empty list as appropriate

Other items:
- Use `other_items` only for substantive agenda content that does not fit any of the dedicated fields above
- Do NOT silently discard content — if it doesn't fit any dedicated field, it belongs in `other_items`
- Routine procedural items (opening, apologies, confirmation of agenda, disclosures of interest heading) do not need to be recorded if no specific names/details are listed

Valid `item_type` values for `other_items`:
- "questions_on_notice" — written questions submitted with prior formal notice
- "correspondence" — correspondence tabled or noted
- "policy_amendment" — a policy change proposed
- "officer_report" — an officer report listed as information item with no recommendation
- "ceremony" — ceremonial agenda items
- "announcement" — mayoral or administrative announcements
- "confidential_item" — a confidential item with no detail disclosed
