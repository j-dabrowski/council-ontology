**`layer2.status` is FAIL if and only if `false_negatives` is non-empty** —
a missed real risk is the one failure mode that gates automated publish.
The other judgment dimensions are recorded for calibration and never flip
`layer2.status` on their own, however many `concern` verdicts they carry.

**Overall `status` is FAIL if `layer1.structural_ok` is `false` OR
`layer2.status` is `FAIL`, otherwise PASS.**

own two-file convention (JSON for code, markdown for a person): a short
summary line, the false-negative list (if any) in full detail, the flag
